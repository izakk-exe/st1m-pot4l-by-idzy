### ◎ Overlay clavier & souris
**W A S D** s'allument pendant que tu joues, un **cercle entoure les touches** et un point suit **la direction de ta souris**. En option : Ctrl, Maj, Espace, clics, boutons latéraux, **molette avec compteur par seconde** et **frise saut / accroupi / molette**. Couleur, taille, position et opacité réglables — idéal pour les clips et le coaching. Raccourci : `Ctrl + Maj + O`.

<p align="center"><img src="assets/readme/overlay.jpg" width="92%" alt="Réglages de l'overlay"></p>

### ⌨️ Packs de binds en un clic
Tap strafe (molette haut/bas = avancer), scroll jump, superglide… Chaque touche déclenche **une seule commande normale du jeu** : **aucune macro, aucune automatisation**.

## 💾 Installation

| | |
|---|---|
| **Installeur** (recommandé) | `ST1M-POT4L-Setup-x.y.z.exe` — se met à jour depuis l'app (*Actus & liens → Vérifier les mises à jour*) |
| **Portable** | `ST1M-POT4L-Portable-x.y.z.exe` — aucune installation, pas de mise à jour automatique |

> **Windows affiche « Windows a protégé votre PC » ?** C'est normal : l'application n'est pas signée (un certificat coûte cher). Clique sur **Informations complémentaires → Exécuter quand même**. Tout le code est visible dans ce dépôt.

**Prérequis** : Windows 10/11. Pour l'**overlay**, mets Apex en mode **Sans bordure** (impossible au-dessus du plein écran exclusif).

## 🔒 Confiance & vie privée

- **Aucun compte, aucun tracking.** Les seules connexions réseau : récupération optionnelle des actus/statuts communautaires et vérification des mises à jour, depuis GitHub.
- **Sauvegardes automatiques** avant chaque modification des fichiers (`%USERPROFILE%\Saved Games\Respawn\Apex`).
- **L'overlay lit localement** uniquement W A S D, Maj, Ctrl, Espace, C, la souris et la molette — via le même mécanisme que les overlays OBS (*Raw Input*). Rien n'est enregistré ni envoyé. Le code : [`electron/input-helper.ps1`](electron/input-helper.ps1).
- **Les entraîneurs mesurent, ils n'envoient jamais rien au jeu.**

> ⚠️ Projet communautaire **non affilié à EA / Respawn**. Modifier des fichiers de config se fait à tes risques ; l'app n'injecte rien dans le jeu, mais **aucune garantie** vis-à-vis d'EasyAntiCheat ne peut être donnée.

<summary><b>🇬🇧 English summary</b></summary>

**ST1M POT4L** is a free Windows app for **Apex Legends**: a config editor that unlocks hidden settings (FOV up to 120, sun shadows, textures, RGB reticle, Reflex…) with **one-click setups**, **before/after previews on real in-game captures**, automatic backups and one-click restore, plus a **Movement Lab**: a 280+ technique catalogue (index of the Apex Movement Wiki) showing *your* keys, a learning path with XP, legend cards and quiz, a **Superglide Trainer**, wheel-cadence and jump-rhythm trainers, and a **keyboard & mouse overlay** (WASD, mouse ring, wheel counter, input timeline).

- **Install:** download from [Releases](https://github.com/izakk-exe/st1m-pot4l-by-idzy/releases/latest). Windows SmartScreen may warn because the app is unsigned: *More info → Run anyway*.
- **Overlay:** set Apex to *Borderless* mode. It only reads W A S D, Shift, Ctrl, Space, C, mouse and wheel, locally.
- **No macros:** every bind triggers one normal game command; the trainers only *measure* inputs.
- **Disclaimer:** community project, not affiliated with EA/Respawn; use at your own risk, no anti-cheat guarantee.
- Web demo: <https://izakk-exe.github.io/st1m-pot4l-by-idzy/> · License: MIT.
