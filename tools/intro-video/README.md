# Intro film (ST1M PORT4L)

The intro video is generated by code — no video editor, no stock music:

- `scenes.js` — every scene, drawn frame by frame on a canvas (pure function of time).
- `audio.js` — the soundtrack, synthesised with WebAudio (drones, risers, impacts, pulses).
- `mp4.js` — a tiny MP4 muxer (H.264 + AAC) so the film is encoded with the browser's WebCodecs.
- `main.js` — renders everything and writes two files to `dist/video/`.

Re-render after editing a text or a timing:

```bash
node tools/intro-video/render.js
```

Requires Node 22+ and Microsoft Edge. Output: a 1080p version and a 720p version under 10 MB for Discord.
